# Skills Index

Herramientas y flujos disponibles para el proyecto URLs-Gallery.

## Skills disponibles

| Skill | Descripción | Uso |
|-------|-------------|-----| 
| `atomic-planner` | Planeación atómica de tareas | Planificar tareas numeradas |
| `discovery-and-scope` | Descubrimiento y definición de alcance | Fases 1-2 del método |
| `gated-builder` | Construcción controlada con verificación | Fases 3-4 del método |
| `project-router` | Enrutamiento de proyectos | Configuración de estructura |
| `stack-advisor` | Asesoramiento de tecnologías | Selección de stack |

## Uso

- Los skills se invocan con `pnpm run skill:<nombre>` o se solicitan al asistente.
- El contexto del proyecto se carga automáticamente desde `context/PROJECT_CONTEXT.md`.
- Se recomienda leer `context/PROJECT_CONTEXT.md` al inicio de cada sesión.
